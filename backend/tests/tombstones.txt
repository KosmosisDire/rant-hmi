# THE DEATH LEDGER'S TEETH (the language-rewrite plan, stage 0).
#
# Every symbol a rewrite stage kills is buried here in the same commit that
# deletes it, and the tombstone ctest greps the source trees for each one —
# so nothing dead ever resurrects quietly. One symbol per line; # lines and
# blank lines are ignored; a hit anywhere in backend/src, backend/tests,
# frontend/src, frontend/test or tools fails the test.
#
# stage 1, the lexer: the parser-side test for "was this operator token spelled
# as a word" — real keyword tokens (KwAnd/KwOr/KwNot) carry the fact now
wordy

# stage 2, the language core: the single-pass parse=typecheck=emit compiler and its
# smeared shape tracker. The Env's object-descriptor roster replaced the flat scope
# maps (ExpressionScope/no_x), the checker's two mutable tracker fields died with it
# (enum_type_), table argument gates became one generic check (arg_shape), and the
# never-driven timer-x path went unported (x_timer).
ExpressionScope
no_x
enum_type_
arg_shape
x_timer

# stage 2 also killed the THIRD hand-rolled arithmetic parser: `every` cadences and
# `keep` bounds now go through THE parser and a constant walk over its AST
fold_const

# stage 3, the view emitter: the SECOND parser (template_expr.cpp's own recursive
# descent) died — the view tier walks THE parser's AST now, and $theme joined the one
# grammar. These are the old descent's methods; one Parser class remains in the repo.
parse_primary
parse_postfix
bespoke_args
address_chain

# stage 4, the semantic deltas: a callable is a METHOD and every method is CALLED
# (x.length(), #f00.r()) — plain after a dot is a field. The bare-reading column
# died with the property⇒method delta.
spec->property

# stage 4, enums first class: `.variant` is an expression resolved at COMPILE against
# the enum its context expects, and the FAULTING runtime text->enum coercion died.
# The corrected conversion (ToEnum, user's call 2026-08-14) is not it: constants
# resolve or refuse at compile, and a dynamic name outside the vocabulary converts
# to Nil and propagates — the buried symbol is the one that faulted. The number/text
# equality leniencies stay dead (.int() / .name() spell the intent).
EnumFromName

# stage 4, recursive field access: the scalar tier's accumulated-path string walk
# died — an object's fields are a recursive TREE (env.h FieldNode) and a `.` is one
# postfix op resolved a level at a time. The word below was the old walk's variable;
# the view tier spells its remaining name-walk `address`, which is what it emits.
qualified

# stage 5a, the typed document: decode ONCE at the compile boundary (doc/decode.h)
# replaced the defensive json-walking each compile-path reader restated — the
# probe-every-use helpers below and the from/to discriminator enum they served.
# The registry-row read-back (compiler.cpp decode_spec) is a decode of the SAME
# discipline and dies with the two-compiler seam at stage 5b.
array_or_empty
side_kind
SideKind
slot_shape

# stage 5b, the Module: a compile RETURNS a value (lang/module.h) — the callback
# seam between lang/ and the program died. The virtual sink interface, its Program
# adapter, the adapter's two allocation verbs (now the Module's own counters), and
# the lambda-body record that dissolved into the Module's nested Procedures.
EmitSink
ProgramEmit
alloc_text_slot
reserve_elems
SubProgram

# stage 5b, the two-compiler seam: the registry is a pure SERVING product now — the
# document compiler reads typed ComponentSpecs derived by the registry's own walk
# (compile/components.h derive_specs), never the served JSON rows. The read-back
# decoder, its string helper, and its armed-template walk over served nodes.
decode_spec
spec_text
decode_armed
component_registry

# stage 5b, the typed destination: the expression wrapper states the destination
# rule ONCE — the shape fit, the cross-enum refusal, and the enum-into-text RENDER
# — for every surface. The per-destination wrapper that restated the render and
# the check for scalar step destinations.
push_typed

# stage 5b, the destination as data: lang/ Dest carries the destination's type,
# label and element declaration into the pipeline, so the fit — the element rules
# included — is checked at the one boundary. The compiler-side element check, its
# refusal builder, and the aggregate-permission side channel beside `expected`.
element_fits
element_refusal
allow_agg

# stage 5b, the rename walks: the FLAT fan-out (descend every element regardless of
# scope) lost its last caller when the scoped walk landed — a flat rewrite is exactly
# the corruption the scope rule exists to prevent, so the pair stays dead.
rename_refs
count_refs

# the rename cutover: THE INDEX decides membership (the compile records every
# resolved name; the rename asks it which occurrences are its variable's) and
# BINDING PRESERVATION replaces the hand checks (recompile after, refuse unless
# every walked reference kept its declaration). The scoped walk that restated the
# scope rules, its shadow-pruned pass, the capture pre-check it fed, and the blind
# identifier rewrite that renamed by spelling rather than by resolution.
rename_scoped
scoped_pass
capture_site
rewrite_ident

# stage 5c, the signature: every Procedure carries {every_tick, reads, writes}
# inferred off its own instructions, and the scheduler and the mesh QUERY it —
# the per-slot dep scan, the per-flow subscription stamping, the slot's stamped
# dep list and the entity's write flag all restated what the code already said.
scan_slot_deps
stamp_flow_reads
dep_entities
flow_writes

# stage 5c, the display reads leave the Module: the attr compile's read set stays
# ITS product — the app serves the live frame off it and hands the read entities
# to the mesh at apply() — so the per-entity read flag and the per-field flag
# vector stamped into the wire compile's entity table restated a fact whose owner
# already held it.
flow_reads

# stage 5c, per-copy derived in place: THE PLACEMENT RULE is one function over the
# authored text (lang/template_expr.h reads_view_input) that each tier asks where
# it stands — the record set that carried the display tier's decisions into the
# document compile, and the old name of the classifier that fed it.
per_copy_expression

# stage 6a, the frame record: the Module's five loose storage counters became ONE
# FrameExtent — the size of the storage a RUN owns, as opposed to what a cell owns —
# and the operand stack moved into the run's Frame. The old counter spellings.
text_slots
elem_values
stack_values
sub_stack

# stage 6a, the element pool: the run's aggregate scratch and its element text
# region live in the Frame now, reset at each fresh run's entry — the state-level
# pool, its cursor pair riding the global text table, and the scheduler-side reset
# every caller had to remember.
reset_scratch
alloc_elems
alloc_elem_text
elem_text_base

# stage 6a, parking keeps the frame: a suspended run's frame SWAPS into its pending
# slot whole and swaps back at resume, so held scratch survives by ownership — the
# per-site runs of deep-copy text slots died with the copying.
pending_texts

# stage 6a, temporaries live in the frame: the struct-slot table is a partitioned
# run of type ids (declared slots first, temporaries after — the boundary says
# where fields live), so the per-slot record whose `temp` flag drove the
# snapshot-and-restore loops around a park died with those loops.
StructDef

# stage 6b, the argument rides the frame: what a run is invoked WITH is frame data
# read by Arg, so the state-resident parameter register (a one-slot array on the
# state) and the pending slot's per-field copy of it died — a park keeps the
# argument because it keeps the frame, and the pin happens in place.
LoadArg
