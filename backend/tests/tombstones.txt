# THE DEATH LEDGER'S TEETH (the language-rewrite plan, stage 0).
#
# Every symbol a rewrite stage kills is buried here in the same commit that
# deletes it, and the tombstone ctest greps the source trees for each one —
# so nothing dead ever resurrects quietly. One symbol per line; # lines and
# blank lines are ignored; a hit anywhere in backend/src, backend/tests,
# frontend/src, frontend/test or tools fails the test.
#
# stage 1, the lexer: the parser-side test for "was this operator token spelled
# as a word" — real keyword tokens (KwAnd/KwOr/KwNot) carry the fact now
wordy

# stage 2, the language core: the single-pass parse=typecheck=emit compiler and its
# smeared shape tracker. The Env's object-descriptor roster replaced the flat scope
# maps (ExpressionScope/no_x), the checker's two mutable tracker fields died with it
# (enum_type_), table argument gates became one generic check (arg_shape), and the
# never-driven timer-x path went unported (x_timer).
ExpressionScope
no_x
enum_type_
arg_shape
x_timer

# stage 2 also killed the THIRD hand-rolled arithmetic parser: `every` cadences and
# `keep` bounds now go through THE parser and a constant walk over its AST
fold_const

# stage 3, the view emitter: the SECOND parser (template_expr.cpp's own recursive
# descent) died — the view tier walks THE parser's AST now, and $theme joined the one
# grammar. These are the old descent's methods; one Parser class remains in the repo.
parse_primary
parse_postfix
bespoke_args
address_chain

# stage 4, the semantic deltas: a callable is a METHOD and every method is CALLED
# (x.length(), #f00.r()) — plain after a dot is a field. The bare-reading column
# died with the property⇒method delta.
spec->property

# stage 4, enums first class: `.variant` is an expression resolved at COMPILE against
# the enum its context expects, so the runtime text->enum coercion opcode died — a
# wrong variant is a finding now, never a fault. The number/text equality leniencies
# went with it (.int() / .name() spell the intent).
EnumFromName
